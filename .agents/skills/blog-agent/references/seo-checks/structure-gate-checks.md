# SEO Article Structure Gate Checks

Use this reference to judge the outline before writing or publishing.

## Universal Pass Criteria

The article must satisfy all of these unless a project-specific rule overrides them:

- Early answer: the lead or first main H2 answers the target query directly.
- H2 progression: H2s move from premise to answer to details to action.
- H3 usefulness: H3s are concrete decision units, not decorative keyword variants.
- Link roles: contextual links, related links, service CTA, final action, and bottom cluster links are separated.
- H2 next-link plan: each major H2 has either a next internal link, a reason for no link, or a service/listing CTA.
- Reader-path hub: parent, decision-support, and service-adjacent articles route readers by condition, audience, location, schedule, concern, or next action when relevant.
- Universal-only benchmark use: benchmark components are filtered to intent satisfaction, crawlable structure, topical clarity, user path clarity, trust, and conversion fit.
- CTA intent fit: CTA timing matches reader readiness.
- Summary: final summary restates the answer and gives one practical next action.
- Trust identity: the article makes clear who the site serves and why it can advise on the topic.
- Benchmark boundary: no competitor wording, order, proprietary claims, or data is copied.

## Type-Specific H2 Flow

### definition

Use for broad parent pages and evergreen explainers.

Expected flow:

1. What it is
2. Difference from adjacent concepts
3. Benefits and drawbacks
4. How it works or how to start
5. Things to know before acting
6. Examples or cases when available
7. Optional question block only when a distinct reader question remains outside the main flow
8. Summary and next action

### duration

Use for timing, period, schedule, weekly commitment, seasonality, or availability.

Expected flow:

1. Direct answer to the duration/timing question
2. Typical periods or timing brackets
3. Weekly days/hours or schedule examples
4. Conditions such as remote, weekend, class schedule, or work style
5. Pros and cons by period or timing
6. How to secure time or choose timing
7. Optional question block only when a distinct reader question remains outside the main flow
8. Summary and next action

### howto

Use for search, choose, apply, compare, prepare, or execute queries.

Expected flow:

1. Recommended methods
2. How to choose among methods
3. Criteria or decision axes
4. Cautions and common mistakes
5. Process or steps
6. Audience-specific question block only when it adds a distinct decision answer
7. Summary and next action

### anxiety

Use for negative, regret, fear, risk, "meaningless", "avoid", "hard", or "suspicious" queries.

Expected flow:

1. Validate the concern
2. State when the concern is true and when it is not
3. Explain common reasons or bad patterns
4. Identify warning signs
5. Show how to judge safely
6. Show how to act next
7. Related concerns only when they are not already answered in the main flow
8. Summary and next action

### selection

Use for interview, screening, acceptance rate, rejection, preparation, or "cannot pass" queries.

Expected flow:

1. Normalize the reader's situation
2. Difficulty or acceptance context
3. Reasons for failure or success
4. Remedies and preparation steps
5. What to do next
6. Optional question block only when it adds a distinct decision answer
7. Summary and next action

### comparison

Use for services, tools, companies, options, rankings, or criteria comparison.

Expected flow:

1. Who the comparison is for
2. Selection criteria
3. Comparison table or ranked list
4. Best choice by user type
5. Cautions and exclusions
6. How to choose and act
7. Optional question block only when it adds a distinct decision answer
8. Summary and next action

## Link Role Rules

Every link should have a job:

- Definition link: sends broad readers to a parent guide.
- Condition link: sends readers to a category, listing, or filter page.
- Concern link: sends readers to an anxiety or related-concern child article.
- Action link: sends readers to application, interview, consultation, or conversion page.
- Cluster link: keeps readers inside the topic area after the article is done.

Avoid:

- repeated generic links after every section
- a link block that has no relation to the preceding H2
- a sidebar, related block, or bottom cluster that is only "popular posts" and not aligned with the article's search intent
- making social share, previous/next posts, ad banners, or competitor-specific widgets mandatory SEO requirements
- final CTA choices that compete with each other
- sending anxious readers directly to hard-sell conversion before they have a judgment framework

## PASS / WARN / FAIL

PASS:

- All universal criteria are satisfied.
- Type-specific flow is satisfied or deviations are explained.
- H2 role map and internal-link plan are explicit.
- Reader-path link hub is explicit when the article is meant to route choices or next actions.

WARN:

- One or two items are missing, but the reason is documented.
- CTA or trust signal is light because the article is intentionally informational.
- Some internal links are unavailable because the site lacks destination pages.

FAIL:

- Missing early answer.
- Missing H2 role map.
- Missing internal-link plan.
- Missing reader-path hub for an article whose value depends on organized next-page routing.
- No summary/next action.
- Benchmark copied too closely.
- Structure is not aligned with the selected article type.
