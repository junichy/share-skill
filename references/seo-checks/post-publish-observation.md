# Post-Publish Observation

Use this after publishing, rewriting, changing titles, strengthening internal links, or fixing schema/live metadata.

## Minimum Evidence

- live URL
- live title, H1, meta description, canonical, dateModified
- live schema and plugin-controlled author/description output
- GSC page/query rows for the target URL
- exact target query exposure
- child-query exposure
- live SERP snapshot when rank or absence matters
- action log date and next check dates

## Observation Windows

- Day 0: verify live HTML and internal links.
- Day 7: look for first impression/query-spread movement, not ranking success.
- Day 14: classify whether the page is entering the right candidate set.
- Day 28: decide whether to rewrite, strengthen links/hub, retarget, or wait longer.

## GSC Readout

Read in this order:

1. Page-level impressions: is Google testing the URL at all?
2. Exact target query: is the page in the candidate set for the intended query?
3. Child queries: is Google only understanding a narrower angle?
4. Unexpected queries: did title/body point Google to the wrong topic?
5. CTR/snippet: if impressions exist but CTR is weak, inspect title/meta/snippet.

## Live Parity Readout

Check the live page, not only local files:

- title and H1
- meta description
- canonical
- author/reviewer/organization if relevant
- datePublished/dateModified
- BlogPosting/Article/Breadcrumb schema
- iframes/images/tables/internal links
- plugin-generated SEO output that may override article-side assumptions

## Decision Rules

- No exact target impressions but child impressions exist: classify `子KW認識`.
- No relevant impressions after indexing and internal linking: classify `候補集合外`.
- Impressions exist but position is poor and lower-page comparison resembles us: fix structure/intent before title polish.
- Impressions exist near page 1 or page 2: compare rank ladder and patch missing top-10 elements.
- AIO/video/image packs dominate: strengthen media/trust surfaces or choose a child query.
